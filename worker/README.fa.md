# چالبازی — API Worker (مرحله اول)

این Worker فقط اعتبارسنجی رسمی Telegram Mini App `initData` را انجام می‌دهد.

## وضعیت فعلی
- `GET /health`: بررسی سلامت سرویس
- `POST /api/auth/telegram`: اعتبارسنجی امضای تلگرام و تازگی `auth_date`
- در این مرحله هیچ اتصال یا نوشتنی به Firebase وجود ندارد.
- امتیاز ارسالی از کلاینت پذیرفته یا ثبت نمی‌شود.

## راه‌اندازی
1. یک Worker مستقل با نام `chalbazi-api` در Cloudflare بساز.
2. محتوای `index.js` را به‌عنوان ورودی Worker قرار بده.
3. مقدار `ALLOWED_ORIGINS` را با دامنه واقعی مینی‌اپ جایگزین کن.
4. در بخش Worker Settings > Variables and Secrets، مقدار `TELEGRAM_BOT_TOKEN` را به‌صورت Secret تنظیم کن.
5. ابتدا `/health` و سپس احراز هویت از داخل خود Telegram Mini App آزمایش شود.

## مرحله‌های بعد
- افزودن محدودیت نرخ درخواست و ثبت رویدادهای امنیتی بدون ذخیره داده حساس.
- طراحی قواعد دسترسی Firebase بر اساس مسیرهای واقعی و نیاز هر بازی.
- انتقال امتیاز، دعوت و مأموریت به endpointهای سمت سرور با اعتبارسنجی مستقل هر رویداد.
- افزودن اعتبارسنجی اختصاصی بازی‌های زنده و اتاق‌ها.
- تنها پس از مهاجرت و تست همه کلاینت‌ها، اعمال قواعد نهایی Firebase.

## هشدار
تا پایان مهاجرت، قوانین عمومی Firebase را تغییر ندهید؛ نسخه فعلی کلاینت به REST عمومی وابسته است. این Worker هنوز جایگزین کامل `score-manager.js` نیست و نباید به‌عنوان سامانه ضدتقلب امتیازدهی معرفی شود.
